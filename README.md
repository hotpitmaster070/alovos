# alovOS

Landing page for **alovOS** — "Mətbəx üçün OS" (an operating system for kitchens): stock, orders and waste in one place.

Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, Inter (`next/font`) and `lucide-react`. Flat, minimal, dark; mobile-first.

## Run locally

```bash
npm install
npm run dev -- -p 4317   # http://localhost:4317
```

Production build: `npm run build && npm start -- -p 4317`. Lint: `npm run lint`.

The page lives in `app/page.tsx`.
